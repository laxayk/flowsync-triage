# Data residency and retention
plan: all
tags: data residency, region, eu, retention, gdpr, deletion
reviewed: 2026-10-13

## Regions
The demo FlowSync service runs in a single region. Choosing a data region is not available.

## Retention
Failed rows are kept for 14 days. Run history is kept as described under Run history. On account deletion, stored credentials and run history are removed within 30 days.

## Legal questions
GDPR, data processing agreements and residency commitments are not covered by this documentation; route them to a person.
