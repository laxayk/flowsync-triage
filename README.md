# FlowSync Triage

AI email triage agent. It watches one support inbox, screens every mail for spam, phishing and prompt injection,
classifies what is left, turns it into tickets, notifies the owner, and drafts replies for one-click approval.

The fictional company is **FlowSync**, a B2B SaaS that syncs records between tools (Salesforce/HubSpot to databases and sheets).

Status: work in progress on `develop`. Backend pipeline first, dashboard and Docker next.
