# Audit log
plan: Business, Enterprise
tags: audit log, activity, changes
reviewed: 2026-10-13

## What it records
The audit log records sign-ins, role changes, connector edits, API key creation and plan changes, with the user and time.

## Access
Admins on Business and Enterprise see it under Settings, Audit log. Entries are kept for 12 months. Export to CSV is available from the same page.
