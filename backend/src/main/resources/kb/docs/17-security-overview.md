## What FlowSync does
Credentials for connectors are stored encrypted and are never shown again after saving. Traffic uses TLS. FlowSync keeps record data only while a run is in progress, plus failed rows for 14 days.

## Certifications
FlowSync is a fictional demo product and has no security or compliance certifications. Questions about SOC 2, ISO 27001, penetration tests or security questionnaires must be routed to a person, not answered from this documentation.
