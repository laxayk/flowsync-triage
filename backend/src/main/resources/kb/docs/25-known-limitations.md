# Known limitations and roadmap
plan: all
tags: limitations, roadmap, not supported, feature request
reviewed: 2026-10-13

## Not available today
Real-time sync, a full dry-run preview, custom objects in Salesforce, Excel and MySQL connectors, data region choice, and an inbound webhook that starts a sync when a source record changes are not available. Starting a run yourself IS available: "Run now" in the dashboard, or the API on Pro and above (see Running a sync manually).

## Feature requests
Support records feature requests for the product team but cannot promise dates or that a feature will be built.
