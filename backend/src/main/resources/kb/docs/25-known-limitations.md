# Known limitations and roadmap
plan: all
tags: limitations, roadmap, not supported, feature request

## Not available today
Real-time sync, a full dry-run preview, custom objects in Salesforce, Excel and MySQL connectors, data region choice, and inbound webhooks that trigger a sync are not available.

## Feature requests
Support records feature requests for the product team but cannot promise dates or that a feature will be built.
