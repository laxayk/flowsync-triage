# HubSpot connector
plan: all
tags: hubspot, connector, oauth, contacts, companies
reviewed: 2026-10-13

## What it syncs
The HubSpot connector reads and writes Contacts and Companies. Deals are read-only.

## Connecting
Connect with OAuth from Connectors, Add. A HubSpot super admin must approve the connection.

## Limits
The connector respects HubSpot API limits and backs off on rate-limit errors.
